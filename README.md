# Frog spearman miniature

First procedural sculpt pass inspired by the supplied warband reference. This is a simplified interpretation, not a detailed reconstruction of the pictured sculpt.

- `models/spearman_28mm.stl`: solid, unsupported STL, dimensions in millimetres.
- `models/spearman_28mm_preview.png`: front and rear views of the actual STL.
- `models/validation.json`: mesh validation results.

25 mm diameter base, 2 mm thick. Frog eye tops are approximately 28 mm above the build plane (26 mm above the base top); spear reaches 38 mm overall. STL contains no unit metadata; import in millimetres. The spear shaft is 1.3 mm diameter.

The exported mesh is one connected, watertight, consistently oriented surface with positive volume and no enclosed internal cavity shells. Keep slicer hollowing disabled: this model is intended to print solid, without drainage holes. It is not presupported. Check orientation, supports and islands in your resin slicer before printing; no physical print has been tested.

Rebuild with Python 3.12:

```sh
python -m venv /workspace/stl-tools
/workspace/stl-tools/bin/python -m pip install -r requirements.txt
/workspace/stl-tools/bin/python tools/build_warband.py
```

Only the spearman is generated by default. Other role sketches in the generator are unfinished and unvalidated.
